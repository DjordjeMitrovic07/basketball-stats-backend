# Basketball Stats – Backend

Spring Boot backend for Basketball Stats web application.

## Tech stack
- Java 17
- Spring Boot (Web, JPA, Validation, Lombok)
- MySQL
- Maven

## How to run
1. Clone the repo
2. Configure `src/main/resources/application.properties` with your MySQL credentials
3. Run the app:
   ```bash
   ./mvnw spring-boot:run
